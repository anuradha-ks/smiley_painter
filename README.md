# Flutter Smiley Painter

A Flutter CustomPainter project that draws interactive smiley faces.

## Features

- CustomPainter-based smiley face drawing
- Mood slider with dynamic expressions
- Classic, Sleepy, and Surprised face types
- Tap gesture to cycle between faces
- Long press to randomize mood and face color
- Toggleable hat, glasses, and mustache accessories
- Undo support for previous configurations
- Responsive layout for portrait and landscape orientations

## Technologies

- Flutter
- Dart
- CustomPainter
- Canvas and Paint
- GestureDetector
